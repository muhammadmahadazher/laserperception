## High-level contents

The full characterization record contains per-condition and per-frame identities, hashes, counts,
detector predictions, available Raw-tracklet ground truth and matching records, capacity/pillar
diagnostics, aggregate metrics, and protocol/environment summaries. The input ledger contains the
frozen drive/frame census, eligible-pose and canonical-frame identities, history/source counts,
timestamps and input hashes, candidate-pillar diagnostics, repeatability identities, and portable
input-reproduction summaries.

These records contain derived evidence. They do **not** contain raw point-cloud arrays or copied
KITTI dataset files.

## Audit method and findings

Both files were checked at their immutable local source paths before release staging:

- byte size and SHA256 matched the frozen identities above;
- each file parsed as JSON;
- recursive key, string, and value-shape inspection found no raw KITTI point-cloud payload,
  dataset-file copy, image binary/base64 blob, checkpoint, ONNX, TensorRT engine bytes, data URI,
  private user identifier, credential, token, private key, or secret;
- path inspection found no private absolute Windows path, `J:\` path, or private Unix home path;
- the largest scalar lists represented bounded metadata such as evaluation indices, source counts,
  time lags, and aggregate sectors—not point rows or binary material; and
- no machine-specific sensitive value requiring redaction was identified.

The files are therefore suitable as planned v0.3.0 GitHub release assets within the project's
evidence-redistribution boundary. They remain untracked because of repository-size discipline.
KITTI data, model artifacts, and generated TensorRT engine binaries remain excluded.
