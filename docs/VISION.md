# Vision — aspirational, not implemented

LaserPerception's long-term ambition is a sensor-aware, eventually sensor-agnostic research framework
for semantic understanding across heterogeneous 3D LiDAR acquisition systems.

Future possibilities include broader semantic segmentation, instance segmentation, detection,
tracking, learned representations, robotics integration, aerial perception, and efficient edge
deployment. None is a current feature or commitment.

The current scope is 3D LiDAR semantic transfer only. There is no 2D LiDAR, detection, tracking,
ROS2, C++ SDK, TensorRT, Jetson optimization, language-model, multimodal-fusion, sensor-streaming,
or foundation-model implementation.
